# 1.0.0 发布说明

公开发布日期：2026-10-26（Windows 成品构建于 2026-10-24）

## 功能

1.0.0 提供 Windows PySide6 桌面应用、安装程序与便携版，包含 AI 今日学习单、自定义学问、三版本笔记、学习地图、间隔复习、学习统计、知识库问答和归档流程。支持 DeepSeek、OpenAI、Anthropic、硅基流动、OpenRouter，以及 OpenAI / Anthropic 兼容自定义网关。加入单实例启动锁，完整学习生成请求的超时为 90 秒。

## 下载

在 [GitHub Release](https://github.com/Uyuh99/daily-knowledge-learning/releases/tag/v1.0.0) 下载：

- `daily-knowledge-learning-setup-v1.0.0.exe`：安装程序，公开文件名使用 ASCII，内容与本地中文名称安装包相同。
- `daily-knowledge-learning-portable-v1.0.0.zip`：便携版，解压完整目录后启动。
- `daily-knowledge-learning-starter-vault.zip`：可选的空白起步学习地图。
- `SHA256SUMS.txt`：发布附件的 SHA-256 校验值。

启动成品无需 Python。首次使用需选择 Vault、配置自己的 AI 服务和密钥，操作步骤见仓库 README。

## 构建

在 Windows 10/11、Python 3.13+、`uv` 和 Inno Setup 6 环境中，从仓库根目录运行：

```powershell
uv sync
./tools/build_windows.ps1
```

成功时脚本生成 `dist/每日知识点学习-安装程序-v1.0.0.exe` 和 `dist/daily-knowledge-learning-portable-v1.0.0.zip`。安装程序按当前用户安装，创建开始菜单快捷方式并默认勾选桌面快捷方式；便携包解压后运行 EXE。`dist/daily-knowledge-learning/` 是未压缩的 onedir 构建目录。

## 基线和限制

本版打包基线为包含 UI 与核心业务模块的集成分支提交。打包脚本中的启动检查确认 EXE 能启动并在检查窗口内保持存活；安装包另需通过安装、快捷方式和卸载验证。代码签名、自动升级、跨机器发布验收以及真实 Vault 的端到端写入验收不属于本版交付范围。首次使用前，请在设置页检查 Vault 路径和 AI Provider 配置。

构建产物不会进入 Git；测试只操作 fixture 和临时目录。请勿将真实 Vault、配置文件或密钥随发布包分享。
