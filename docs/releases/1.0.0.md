# 1.0.0 发布说明

日期：2026-10-19

## 功能

1.0.0 提供 Windows PySide6 桌面应用和 PyInstaller onedir 构建方式，包含每日学习、笔记浏览、学习地图、设置与归档工作流，以及 AI Provider、三版本笔记管理、地图解析和轻量本地检索模块。

## 构建

在 Windows 10/11、Python 3.13+ 和 `uv` 环境中，从仓库根目录运行：

```powershell
uv sync
./tools/build_windows.ps1
```

成功时脚本打印产物绝对路径、EXE 字节数和存活验证结果。可双击 `dist/daily-knowledge-learning/daily-knowledge-learning.exe` 启动。分发时请提供整个 `dist/daily-knowledge-learning/` 目录。

## 基线和限制

本版打包基线为包含 UI 与核心业务模块的集成分支提交。打包脚本中的启动检查仅确认 EXE 能启动并在检查窗口内保持存活。代码签名、安装器、自动升级、跨机器发布验收以及真实 Vault 的端到端写入验收不属于本版交付范围。首次使用前，请在设置页检查 Vault 路径和 AI Provider 配置。

构建产物不会进入 Git；测试只操作 fixture 和临时目录。请勿将真实 Vault、配置文件或密钥随发布包分享。
