# 项目清单

项目目标：提供 Windows 桌面应用，帮助用户每天学习心理学与经济学知识点，并以可审查的方式维护 Obsidian Markdown 笔记。

## 已纳入项目

- [x] PySide6 桌面应用入口：每日学习、笔记、学习地图、设置和归档界面
- [x] AI Provider 接口及 OpenAI、Anthropic、mock Provider
- [x] 学习前、交流后、AI 参考三版本笔记的创建与更新
- [x] 学习地图解析、状态读取和本地轻量检索
- [x] Windows onedir EXE 可复现构建；双击 `dist/daily-knowledge-learning/daily-knowledge-learning.exe` 启动，并在设置页展示版本
- [x] 用户请求：提供 EXE 双击启动方式，并将此交付项写入项目清单（YZFD-34）
- [x] 本地测试覆盖业务模块与 UI 行为
